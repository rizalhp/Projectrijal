# Banking Customer Analytics & Churn Intelligence

## Featured Data Portfolio Project

### [Open the complete project](banking-customer-analytics/)

End-to-end retail banking analytics case study using **SQL, Python, machine learning, Streamlit, and automated testing**. The project builds a leakage-safe customer snapshot, analyzes churn and revenue at risk, and ranks customers for retention prioritization.

**Highlights:** 8,000 synthetic customers · 172K+ monthly activity rows · SQLite analytics layer · churn model · interactive dashboard · CI tests.

> All project data is synthetic and privacy-safe. No real bank or customer data is included.
